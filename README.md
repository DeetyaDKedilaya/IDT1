# FocusFlow - Digital Detox Solution

A modern, user-friendly website designed to help young adults (18-25) manage their smartphone usage and develop healthier digital habits through mindful usage, not restriction.

## Features

### 🧠 Focus Mode
- **Pomodoro Timer**: Customizable focus sessions (15, 25, 45, 60 minutes)
- **Multiple Modes**: Focus, Short Break, and Long Break sessions
- **Visual Feedback**: Color-coded timer display and progress indication
- **Completion Notifications**: Celebrates successful focus sessions

### 📊 Screen Time Tracker
- **Daily Usage Visualization**: Circular progress chart showing daily screen time
- **Weekly Overview**: Bar chart displaying usage patterns over the week
- **App Breakdown**: Categorized time spent on different app types
- **Real-time Updates**: Live tracking and visual feedback

### ⏰ Mindful Break Reminders
- **Customizable Intervals**: Set reminders every 30, 60, 90 minutes, or 2 hours
- **Smart Suggestions**: Randomized break activities for mental and physical wellness
- **Flexible Controls**: Start, skip, or snooze break reminders
- **20-20-20 Rule**: Built-in eye strain prevention reminders

### 🎯 Gamified Goals System
- **Progress Tracking**: Visual progress bars for all goals
- **Achievement System**: Unlock badges for reaching milestones
- **Custom Goal Creation**: Set personalized targets for different timeframes
- **Streak Counters**: Track daily consistency and motivation

### 🏆 Key Achievements
- **First Focus**: Complete your first focus session
- **3-Day Streak**: Maintain goals for 3 consecutive days
- **Week Warrior**: Complete all weekly goals
- **Digital Minimalist**: Stay under screen time goal for 7 days

## Technology Stack

- **HTML5**: Semantic structure and accessibility
- **CSS3**: Modern styling with CSS Grid, Flexbox, and custom animations
- **Vanilla JavaScript**: Interactive functionality and data persistence
- **Canvas API**: Custom charts and visualizations
- **Local Storage**: Persistent data storage
- **Web Notifications API**: Break reminders and achievement notifications

## Design Principles

### User-Centered Design
- **Non-restrictive Approach**: Encourages mindful usage rather than forcing disconnection

### Responsive Design
- **Mobile-First**: Optimized for smartphones and tablets
- **Cross-Platform**: Works on all modern browsers
- **Accessible**: WCAG compliant design patterns

### Visual Design
- **Calming Color Palette**: Reduces digital eye strain
- **Modern UI**: Clean, minimalist interface
- **Smooth Animations**: Enhanced user experience with CSS transitions

## Getting Started

1. **Open the Website**: Simply open `index.html` in any modern web browser
2. **Set Your First Goal**: Navigate to the Goals section and create a personal target
3. **Start a Focus Session**: Use the Focus Mode timer for your first productive session
4. **Configure Break Reminders**: Set up personalized break intervals in the Breaks section
5. **Track Your Progress**: Monitor your digital wellness journey in the Tracker section

## Local Development

To run the website locally:

```bash
# Navigate to the project directory
cd focusflow

# Start a simple HTTP server (Python 3)
python3 -m http.server 8000

# Or using Node.js
npx http-server

# Open browser to http://localhost:8000
```
